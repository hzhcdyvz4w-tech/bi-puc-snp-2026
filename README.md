# BI Executivo PUC — Versão 6 (confronto auditável)

Abra `index.html` no navegador ou consulte o GitHub Pages do repositório.

## Funcionalidades

- Visão geral, Base SIOP, Projetos PUC, Confronto auditável, Documentos.
- Importação SIOP via XLSX; cruzamentos individuais SIOP/SEI/Balanço/Docas, com Portal como quinta fonte opcional.
- Registro manual documentado; importação CSV padronizado de dados previamente conferidos; relatórios DE/PARA; salvar/restaurar sessão JSON.
- Segurança por desenho: a aplicação está em repositório **público** e jamais transmite as evidências inseridas ao GitHub/servidor; elas são processadas em memória do navegador. Não usar com material sigiloso ou sensível sem autorização e hospedagem segura apropriada.

A data de extração SIOP não consta da planilha inicial; sem data de corte comprovada, não há comparação numérica com outras fontes. Homologação da SNP não está automatizada.

Ver [auditoria e limitações](docs/AUDITORIA_CONFRONTO_V6.md).
